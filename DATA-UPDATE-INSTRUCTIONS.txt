DEMO WEBSITE DATA UPDATE
========================

1. GitHub se latest candidates.json download karke isi folder me rakhein. Yeh zaroori hai, taki purane candidates aur tokens preserve rahen.
2. Excel me same 11 headings rakhein. Excel me sirf naye candidates rakh sakte hain.
3. PowerShell kholkar outputs folder me jayen.
4. Ye command chalayein:

   .\convert-excel-to-json.ps1 -ExcelFile "C:\path\to\your-data.xlsx"

5. Script do files banayegi:
   - candidates.json (website data)
   - candidate-links.csv (har candidate ka exact 400-character token wala link)
6. Purane Candidate IDs skip honge; unka data aur token bilkul nahi badlega. Sirf unique naye Candidate IDs add honge.
7. Nayi candidates.json aur candidate-links.csv dono ko GitHub repository me upload/replace karein.
8. Commit changes dabayein. GitHub Pages 1-3 minute me update ho jayega.
9. Candidate ka link candidate-links.csv se copy karein.

   Har generated token exactly 400 characters ka hoga. Pura URL domain aur ?token= milakar isse lamba hoga.

Candidate ID aur Document ID unique rakhein.
Public page ka DEMO / NOT OFFICIAL banner na hatayein.
